# Nullaconexio Docs

**A lightweight, privacy-focused presentation editor.**

Nullaconexio Docs is a simple, offline-friendly presentation editor designed to provide the essentials without the bloat of traditional office suites.

Built around a single HTML file and SVG-based slides, it aims to make creating presentations straightforward while keeping your work under your control.

## ✨ Features

- **Lightweight** — A single HTML file contains the editor.
- **SVG-based slides** — Presentations use individual SVG files for slides.
- **Text editing** — Add and edit text on your slides.
- **Image support** — Add images to your presentations, including embedded images.
- **Import and export** — Import supported content and export your work.
- **Offline-friendly** — Run the editor locally without requiring a cloud account.
- **Privacy-focused** — Designed without telemetry.
- **No unnecessary bloat** — Focuses on essential presentation features.

## 🚀 Getting Started

1. Download or clone this repository.
2. Open the HTML editor file in a compatible web browser.
3. Create your presentation using the available editing tools.
4. Export your work when you're finished.

No account or cloud workspace is required to run the editor locally.

## 🖼️ Images

Nullaconexio Docs supports adding images to slides.

- Remote image URLs may require an internet connection.
- Local or embedded images can be used for offline workflows.
- Make sure you have permission to use any images you include.

## 🔒 Privacy & Offline Use

Nullaconexio Docs is designed with privacy and independence in mind.

The editor is intended to run locally, without requiring a cloud-based presentation service or account. It is designed without telemetry.

For the most reliable offline experience, use local or embedded assets rather than resources hosted online.

## 🎯 Design Philosophy

Nullaconexio Docs prioritizes:

- Simplicity over complexity
- Essential features over feature bloat
- Local workflows over forced cloud dependence
- Privacy over unnecessary tracking
- User control over platform lock-in

The goal isn't to recreate every feature of a massive presentation suite. It's to provide a practical alternative for people who want a simpler tool.
